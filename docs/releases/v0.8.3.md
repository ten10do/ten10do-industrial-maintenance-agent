# Industrial Maintenance Agent v0.8.3

Patch release for cross-platform RAG metadata handling.

## Fixed

- Fixed RAG document-name extraction when Windows-style source paths are
  consumed on Linux/POSIX. `Path(source).name` treats a backslash as a
  separator only on Windows, so the local RAG provider returned the whole
  corpus path as `document` when the agent ran on a POSIX host while the
  corpus metadata had been authored on Windows.
- Document metadata now produces the same file name on Windows and Linux. The
  file name is split on both separators explicitly, so the mapping no longer
  depends on the host platform.
- No planner logic, benchmark dataset, evaluation metric, or tool contract
  changed.

## Validation

- GitHub Actions CI passes on ubuntu-latest (pytest, `ruff check`,
  `ruff format --check`, `mypy`).
- Existing cross-platform regression test remains enabled. The fix makes its
  assertion hold on both platforms; no test was removed or weakened.
- Benchmark reports and the frozen 49-case dataset remain unchanged.

## Compatibility

No API-breaking changes.
